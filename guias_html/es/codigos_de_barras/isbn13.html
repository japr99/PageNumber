Guía de Códigos de Barras — ISBN-13

Qué es y para qué sirve

El ISBN-13 es el código de barras de los libros. Es en realidad un EAN-13
reservado para la numeración de libros (código ISBN). Está pensado para que librerías,
editoriales y almacenes identifiquen cada título.

Puede llevar, además del código, una cabecera de texto "ISBN" encima de las barras
para que quede claro que es un libro.

Qué guarda el código

Solo números (sin letras ni símbolos), y debe cumplir dos reglas:

  • Exactamente 13 dígitos.
  • Debe empezar por 978 o 979 (es el prefijo reservado para libros).

El último dígito es el dígito de control, que se comprueba para que el lector sepa
si el código se ha leído bien.

Valor de muestra y columna Excel

Por defecto muestra un valor de ejemplo. También puedes usar una columna de
Excel: al seleccionarla se validan todas las filas y, si alguna está vacía,
no tiene 13 dígitos, no empieza por 978/979 o el dígito de control falla,
aparece en el visor del diálogo indicando qué fila tiene el problema.

El origen de los datos

Como en todas las simbologías, el valor del código puede salir de tres sitios:

Origen Qué hace
Texto fijo Escribes el valor a mano en el perfil
Columna de datos externos El valor viene de una columna de Excel/CSV, fila a fila
Numeración interna El valor se genera con una máscara (p. ej. 0000 → 0001)

Para las 3 se aplican las mismas reglas del código (tamaño, etc.).

La cabecera "ISBN" y los dígitos

  • Los dígitos van dentro del código, entre las barras (como en el EAN).
  • Además puedes activar la cabecera "ISBN" que se dibuja encima de las barras
    con el texto ISBN + número. Se activa o desactiva con el campo Cabecera.

Campos del diálogo

Campo Qué hace
Ancho Tamaño horizontal del código
Alto Altura del código
Fuente Tipo de letra de los dígitos del código
Cuerpo Tamaño de letra de los dígitos. 0 = sin texto
Cabecera Muestra u oculta el texto "ISBN" encima de las barras

El tipo de letra de los dígitos (Fuente)

Los dígitos del código se dibujan con la letra que elijas en el campo Fuente.

Las letras OCR (OCR-A, OCR-B y sus variantes) son las clásicas de los códigos de
barras: cada cifra está diseñada para que el lector la distinga sin errores. No
incluyen caracteres especiales (la ñ, acentos como á/é, ni símbolos); es una
tipografía propia del código de barras. Como el ISBN es solo números, la OCR es la
recomendada. Si tu texto necesitara caracteres especiales, usarías Helvetica (en Mac)
o Arial (en Windows), que son las fuentes normales y sí los tienen — aunque en el ISBN
solo entran dígitos.

Errores típicos

Error Causa Solución
Debe tener 13 dígitos El ISBN tiene otra longitud Comprueba la cifra (13 dígitos)
Debe comenzar con 978 o 979 El prefijo no es de libro Usa un ISBN válido (978/979)
El dígito de control no coincide Última cifra mal calculada Recalcula el dígito de control
Dato vacío en columna Alguna fila no tiene valor Rellena la fila o quita esa fila de la columna
