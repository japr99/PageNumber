Guía de Códigos de Barras — UPC-A / UPC-E

Qué es y para qué sirve

El UPC es el código de barras de producto más usado en Estados Unidos y
Canadá (el "primo americano" del EAN). Por eso lo verás en productos de Norteamérica
o en etiquetas pensadas para ese mercado. Es un código numérico de barras verticales.

Variante Dígitos Para qué se usa
UPC-A 12 Código estándar de producto en EEUU/Canadá
UPC-E 6 Versión reducida para productos pequeños

El UPC-E es una forma compacta del UPC-A: guarda la misma información con menos
dígitos cuando el código lo permite, ideal para etiquetas con poco espacio.

Qué guarda el código

Solo números (sin letras ni símbolos).

  • UPC-A: exactamente 12 dígitos. El último es el dígito de control, que se
    comprueba para que el lector sepa si el código se ha leído bien.
  • UPC-E: exactamente 6 dígitos. El primer dígito debe ser 0 o 1 (identifica la
    familia de números del sistema). El resto son los datos.

Como es un código de producto, funciona igual que el EAN: los números van dentro del
código, entre las barras.

Valor de muestra y columna Excel

Por defecto muestra un valor de ejemplo. También puedes usar una columna de
Excel: al seleccionarla se validan todas las filas y, si alguna está vacía,
no tiene los dígitos correctos o el dígito de control falla, aparece en el
visor del diálogo indicando qué fila tiene el problema.

El origen de los datos

Como en todas las simbologías, el valor del código puede salir de tres sitios:

Origen Qué hace
Texto fijo Escribes el valor a mano en el perfil
Columna de datos externos El valor viene de una columna de Excel/CSV, fila a fila
Numeración interna El valor se genera con una máscara (p. ej. 0000 → 0001)

Para las 3 se aplican las mismas reglas del código (tamaño, etc.).

Los dígitos del código

En el UPC los números van dentro del código, entre las barras, como parte del
propio símbolo (no es un bloque de texto aparte que puedas mover). Ajustas su tamaño
con la casilla Cuerpo.

Campos del diálogo

Campo Qué hace
Ancho Tamaño horizontal del código
Alto Altura del código
Fuente Tipo de letra de los dígitos del código
Cuerpo Tamaño de letra de los dígitos. 0 = sin texto

A diferencia del QR, el PDF417 o el Code 128, en el UPC no se puede mover el
texto alrededor del código: los dígitos van fijos dentro de las barras.

El tipo de letra de los dígitos (Fuente)

Los dígitos del código se dibujan con la letra que elijas en el campo Fuente.

Las letras OCR (OCR-A, OCR-B y sus variantes) son las clásicas de los códigos de
barras: cada cifra está diseñada para que el lector la distinga sin errores. No
incluyen caracteres especiales (la ñ, acentos como á/é, ni símbolos); es una
tipografía propia del código de barras. Como el UPC es solo números, la OCR es la
recomendada. Si tu texto necesitara caracteres especiales, usarías Helvetica (en Mac)
o Arial (en Windows), que son las fuentes normales y sí los tienen — aunque en el UPC
solo entran dígitos.

Errores típicos

Error Causa Solución
Debe tener 12 dígitos El UPC-A tiene otra longitud Comprueba la cifra (12 dígitos)
Debe tener 6 dígitos El UPC-E tiene otra longitud Comprueba la cifra (6 dígitos)
El primer dígito debe ser 0 o 1 El UPC-E empieza por otra cifra Cambia el primer dígito a 0 o 1
El dígito de control no coincide Última cifra mal calculada Recalcula el dígito de control
Dato vacío en columna Alguna fila no tiene valor Rellena la fila o quita esa fila de la columna
