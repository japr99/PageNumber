Guía de Códigos de Barras — ITF-14

Qué es y para qué sirve

El ITF-14 es un código de barras pensado para cajas, palés y envases de
transporte (no para el producto en el lineal). Es el "código grande de la
logística": se imprime directamente sobre el cartón y se usa para identificar la
unidad de envío (una caja que contiene varias unidades). Suelen leerlo escáneres de
almacén.

Se basa en la simbología Interleaved 2 of 5, pero con un tamaño y un formato fijos
pensados para el transporte.

Que guarda el código

GTIN-14 (14 dígitos) normalmente, o GTIN-13 (13 dígitos) que el programa
convierte. Solo números. El último dígito es el dígito de control.

  • GTIN-14: exactamente 14 dígitos. El primer dígito es el indicador (0 a 8)
    que suele distinguir niveles de la caja (p. ej. 1 = caja, 2 = palé…).
  • GTIN-13: exactamente 13 dígitos. Si lo eliges, el programa le añade un 0 al
    inicio     y recalcula el dígito de control para convertirlo en GTIN-14.

El diálogo te deja elegir entre GTIN-14 y GTIN-13 según el dato que tengas.

Tipo de impresora

El ITF-14 imprime su texto según el tipo de impresión elegido (Flexo, Térmica o
Láser). Esto ajusta automáticamente las dimensiones mínimas del código (altura y
el grosor del borde, la "barra de soporte" alrededor) para que se pueda leer según el
método de impresión.

  • Flexo (impresión en cartón): necesita el código más grande y un borde más
    grueso.
  • Térmica / Láser: admiten un código más pequeño y un borde más fino.

Solo tienes que elegir cómo vas a imprimir; el programa ya propone los mínimos
correctos para ese método.

El texto legible

Bajo el código se muestra el número formateado en bloques al estilo logístico,
p. ej. 1 08 1234 567008 8 (agrupado como manda el estándar). Puedes colocarlo
debajo o encima del código, y ajustar su tamaño con la casilla Cuerpo.

Este texto se dibuja con la fuente del código (OCR por defecto), sin necesidad de
elegir letra.

Valor de muestra y columna Excel

Por defecto muestra un valor de ejemplo. También puedes usar una columna de
Excel: al seleccionarla se validan todas las filas y, si alguna está vacía,
no tiene los dígitos correctos o el dígito de control falla (según sea GTIN-14
o GTIN-13), aparece en el visor del diálogo indicando qué fila tiene el problema.

El origen de los datos

Como en todas las simbologías, el valor del código puede salir de tres sitios:

Origen Qué hace
Texto fijo Escribes el valor a mano en el perfil
Columna de datos externos El valor viene de una columna de Excel/CSV, fila a fila
Numeración interna El valor se genera con una máscara (p. ej. 0000 → 0001)

Para las 3 se aplican las mismas reglas del código (tamaño, tipo de impresora, etc.).

Campos del diálogo

Campo Qué hace
Ancho Tamaño horizontal del código
Alto Altura del código
Cuerpo Tamaño de letra del texto legible. 0 = sin texto
Posición Lugar del texto: debajo o encima del código
Distancia Espacio entre el código y el texto
Tipo GTIN-14 (14 dígitos) o GTIN-13 (13 dígitos)
Impresora Flexo / Térmica / Láser (ajusta los mínimos)

Para ocultar el texto legible, pon Cuerpo en 0: el código se queda solo,
sin texto alrededor.

Errores típicos

Error Causa Solución
Debe tener 14 dígitos El GTIN-14 tiene otra longitud Comprueba la cifra (14 dígitos)
Debe tener 13 dígitos El GTIN-13 tiene otra longitud Comprueba la cifra (13 dígitos)
El dígito de control no coincide Última cifra mal calculada Recalcula el dígito de control
Dato vacío en columna Alguna fila no tiene valor Rellena la fila o quita esa fila de la columna
