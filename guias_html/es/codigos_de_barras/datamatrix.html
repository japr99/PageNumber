Guía de Códigos de Barras — DataMatrix

1. DataMatrix (familia de simbologías)

El DataMatrix es un código bidimensional que puede trabajar de tres formas
distintas, según la opción que elijas en el selector:

Opción del selector Qué guarda el código
DataMatrix personalizado Cualquier texto libre (datos propios, varias líneas, una URL…)
GS1 DataMatrix Datos GS1 en formato(AI)valor: (01)...(17)...
DataMatrix GS1 Digital Link Los mismos datos GS1, pero dentro de unadirección web (URL)

Las tres comparten la configuración física del código (tamaño, formato y
texto legible bajo el símbolo), que se explica al final de esta sección. Lo que
cambia entre ellas es qué escribes en los datos. A continuación se detalla
cada una.

1.1 DataMatrix personalizado

Es el DataMatrix "normal": guarda lo que quieras, sin validar ningún
estándar. Solo comprueba que no esté vacío.

  • Una sola línea: escribe el texto directamente.
  • Varias líneas: usa el carácter separador (\| por defecto) entre cada
    texto; cada bloque separado será una línea distinta.

Ejemplos:

Cliente: 1001 | Nombre: Maria Garcia Lopez | DNI: 12345678Z
ABC12345
https://ejemplo.com/producto

El primero genera 3 líneas legibles (una por cada |). Los otros generan una
sola. Resulta útil para meter datos propios de tu software sin seguir GS1.

Adaptar el código al lector (inicio y fin de campo)

Para que la app lectora distinga cada campo, defines dos controles:

  • Apertura: carácter que marca el inicio de cada campo.
  • Cierre: carácter que marca el fin de cada campo.

El programa parte el dato en campos usando estos caracteres (quita la apertura
inicial, divide por cierre+apertura, limpia el cierre del último). Cada campo
aparece como una línea legible bajo el código y así la app lectora identifica
dónde termina uno y empieza el siguiente.

  • Valor interno — el botón "Editar texto" abre una ventana: escribes el
    dato, defines apertura y cierre y ves en vivo cómo queda cada campo.
  • Dato externo — al elegir la columna, el programa intenta detectar el
    separador automáticamente (prueba varios caracteres hasta encontrar el que
    divide las filas en el mismo número de campos). Es solo una propuesta y no
    es del todo fiable     —si el carácter también aparece dentro de los datos
    (p. ej. comas en una dirección) o las filas no tienen siempre el mismo número
    de campos, puede acertar el candidato equivocado o quedarse con | por
    defecto—; revisa siempre que Apertura y Cierre coincidan con el separador real.

En los archivos de datos de ejemplo tienes columnas con separadores distintos para
probar:

Columna Separador Apertura / Cierre en el perfil
datamatrix_pipe \| vacía /\|
datamatrix_semicolon ; vacía /;
datamatrix_chevron << >> << / >>
datamatrix_brace { } { / }

Ejemplo con apertura << y cierre >>:

<<Cliente: 1001>><<Nombre: Maria Garcia Lopez>><<DNI: 12345678Z>>

→ tres campos: "Cliente: 1001", "Nombre: Maria Garcia Lopez", "DNI: 12345678Z".

Con Apertura vacía y Cierre | es el comportamiento clásico:
Cliente: 1001 | Nombre: ... | DNI: ....

Con ambos separadores vacíos, el dato es un único campo.

Estas líneas de texto no tienen por qué quedar siempre bajo el código: puedes
posicionarlas en cualquier lugar alrededor del mismo (debajo, encima,
a la izquierda o a la derecha) y alinearlas en las 9 posiciones posibles
(superior / medio / inferior × izquierda / centro / derecha) con los campos
Posición HRI y Alineación HRI del perfil.

1.2 GS1 DataMatrix

Variante para identificación de productos con el estándar GS1. Los datos se
organizan por Application Identifiers (AI) — cada AI es un número que
identifica qué significa el valor que le sigue.

Formato de entrada

Cada bloque se escribe como (AI)valor sin espacios entre bloques:

(01)09506000117843(17)250124(10)POIG8F(21)1CBFNO6B9M

Los paréntesis son solo para lectura humana. Al generar el código se eliminan y
se inyecta un carácter separador invisible entre campos variables.

Ejemplos comunes

Producto + lote + fecha (01)09506000117843(17)250124(10)LOTE001
Producto + serie (01)09506000117843(21)SERIE12345
Producto + lote + serie (01)09506000117843(10)LOTE001(21)SERIE12345

Columna Excel

Cada celda debe contener el formato completo con paréntesis:

(01)09506000117843(17)250124(10)POIG8F(21)1CBFNO6B9M

Al seleccionar la columna se validan todas las filas. Si hay errores aparecen
en el visor del diálogo indicando qué filas fallan y por qué. Los datos GS1 no se
parten por separadores: usan su propia estructura, y por eso se muestra la etiqueta
"Datos GS1 detectados".

AI 10 sin valor El lote está vacío Añade el número de lote

1.3 DataMatrix GS1 Digital Link

Fuente de esta explicación: estándar GS1 Digital Link de GS1 Spain
(https://www.gs1es.org/estandares-gs1-identificar/gs1-digital-link/).

¿Qué es?

GS1 Digital Link es el estándar de GS1 que inserta el sistema de
identificación GS1 dentro de una dirección web (URL). El código de barras ya no
guarda solo "el número de producto", sino un enlace que lleva a la página web
de ese producto.

La gran ventaja es cómo se lee: hoy, la mayoría de la gente lleva un móvil que
no entiende un GS1 clásico, pero cualquier móvil escanea una URL con la cámara
y abre la web automáticamente. Aunque GS1 Digital Link se popularizó con el QR,
también puede ir en un DataMatrix, que es justo esta opción del selector.

¿Qué le aporta a tu cliente (y a ti)?

  • Acceso directo a contenido: el consumidor escanea y ve ingredientes,
    alérgenos, instrucciones de uso, recetas, productos relacionados o la tienda
    online de la marca.
  • Menos etiquetas: concentra en un solo código toda la información que hoy
    obligaría a imprimir varias etiquetas o varios códigos.
  • Trazabilidad: con el lote, la fecha de caducidad o consumo preferente dentro
    del código se pueden retirar del almacén productos caducados, con alertas
    alimentarias o falsificados.
  • Devoluciones más fáciles para el distribuidor y mejor intercambio de
    datos     con los socios comerciales.
  • Implantación gradual: puedes empezar solo con el GTIN (el caso más
    simple) e ir añadiendo más "identificadores de aplicación" según lo necesites.
  • Sostenibilidad y pasaporte digital de producto: permite enlazar datos de
    huella de carbono, reciclaje o reacondicionamiento (requisito que impulsa la
    Unión Europea).

¿Cómo se diferencia del GS1 DataMatrix de siempre?

Ambos usan los mismos identificadores (AI) y son funcionalmente
equivalentes: dicen lo mismo sobre el producto. La diferencia es solo cómo se
escriben los datos:

GS1 DataMatrix (element string) GS1 Digital Link (URL)
Forma de escribir (01)09506000117843(17)250124 https://id.gs1.org/01/09506000117843/...
Quién lo lee Escáneres industriales Móvil con cámara (abre la web)
Utilidad Inventario y logística Conectar con el consumidor y la web

Formato de entrada

Un GS1 Digital Link es una URL que incluye el dominio de GS1 y, a
continuación, los identificadores (AI) separados por barras /. Los campos de
longitud variable (como el lote o el número de serie) se escriben también en el
enlace y, si hace falta, los campos de fecha van al final como parámetros ?:

https://id.gs1.org/01/{GTIN}/10/{lote}?17={caducidad}&21={serie}

Ejemplo real:

https://id.gs1.org/01/09506000117843/10/POIG8F?17=250124&21=1CBFNO6B9M

Ejemplos comunes

Uso Ejemplo (URL GS1 Digital Link)
Producto + lote + serie https://id.gs1.org/01/09506000117843/10/LOTE001?21=SERIE12345
Producto + lote + fecha https://id.gs1.org/01/09506000117843/10/LOTE001?17=250124
Producto + serie + fecha https://id.gs1.org/01/09506000117843/10/LOTE001?17=250124&21=SERIE12345

Regla importante con las fechas

Los identificadores de longitud fija con fecha (como el 17 de caducidad, el
15 de consumo preferente…) pueden ir en el enlace antes de un campo
variable, pero una vez que aparece un campo variable (como el lote 10 o el
serie 21), las fechas pasan a los parámetros ? del final. Esta regla la
impone el propio estándar y el programa la valida automáticamente.

Columna Excel

Puedes usar una columna de Excel con una URL completa GS1 Digital Link por celda.
Al seleccionar la columna se validan todas las filas: cada valor tiene que ser
una URL GS1 Digital Link válida (no vale una dirección web cualquiera).

  • Si necesitas guardar una URL libre sin validar, usa la variante
    DataMatrix personalizado en lugar de esta.

Errores típicos

Error Causa Solución
URI GS1 Digital Link inválida: ... La dirección no cumple el estándar Revisa que empiece porhttps://id.gs1.org/01/...
URI GS1 Digital Link inválida Pusiste una URL normal sin GTIN 01 Usa DataMatrix personalizado o añade01/{GTIN}

Consejo: si el dato es un enlace largo, recuerda que, como en las otras dos
variantes, el código se hace más grande y más cuadrado (ver "Tamaños del
código" más abajo). Con URLs muy largas solo quedará disponible el formato
cuadrado.

Campos del diálogo

Son los mismos que el resto de la familia DataMatrix (ver 1.4). En esta
variante no hay separadores de campo: el texto legible bajo el código muestra la
URL completa.

El tipo de letra del texto (Fuente)

El texto legible que acompaña al código se dibuja con la letra que elijas en el
campo Fuente.

Las letras OCR (OCR-A, OCR-B y sus variantes) son las clásicas de los códigos de
barras: cada cifra está diseñada para que el lector la distinga sin errores. No
incluyen caracteres especiales (la ñ, acentos como á/é, ni símbolos); es una
tipografía propia del código de barras. Si tu texto necesita esos caracteres, elige
Helvetica (en Mac) o Arial (en Windows), que son las fuentes normales y sí
los tienen.

Tamaños del código

  • El Alto no se escribe: es un selector con los 3 tamaños estándar GS1 que
    se calculan segun el ancho para DataMatrix (si el dato es largo, solo habrá 1:
    el cuadrado)    .
  • Elige el que mejor se adapte a tu etiqueta; el programa calcula el resto.

¿Cómo se calcula el tamaño mínimo?

El código de barras no puede ser más pequeño de lo que sus propios datos
permiten: cuantos más datos contiene, más módulos necesita y más ancho mínimo
ocupa.

El programa calcula ese mínimo a partir de los datos que vas a imprimir:

  • Con un valor de muestra: el mínimo se calcula con ese único valor.
  • Con una columna de Excel: se recorren todas las filas y se calcula el
    tamaño que generaría cada una. El mínimo final es el de la fila que contiene
    más datos     (la que genera el código más grande).

Así, aunque cada fila tenga distinta cantidad de datos, todos los códigos de la
columna se imprimen con el mismo tamaño: el mínimo necesario para que el código
más grande quepa.

Si escribes un ancho menor que el mínimo, el programa lo ajusta automáticamente
al valor mínimo. El selector de Alto se recalcula para ofrecerte los 3
tamaños GS1 posibles para ese ancho.

Dato largo → solo cuadrado

Por limitaciones del estándar GS1, los formatos rectangulares (16×36, 16×48) solo
admiten hasta 49 caracteres.

  • Dato ≤ 49 caracteres → 3 opciones de alto (cuadrado + 2 rectangulares).
  • Dato > 49 caracteres → solo queda el cuadrado: el alto no cambia (es
    igual al ancho) y el selector de alto solo muestra 1 sola opción.

Resumen: cuanto más largo el dato, más grande y más cuadrado el código. No es un
fallo del programa, es una limitación del estándar GS1.
