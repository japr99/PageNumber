Guía de Códigos de Barras — Code 128

Qué es y para qué sirve

El Code 128 es un código de barras unidimensional (solo barras verticales en una
línea) muy versátil. Es de los más usados en etiquetas de producto, logística,
gestión de inventario y archivos: sirve para codificar letras, números y símbolos.

El nombre viene de que su conjunto de caracteres cubre los 128 caracteres ASCII,
es decir, prácticamente todo lo que puedes escribir en un teclado.

Qué guarda el código

Puede guardar cualquier texto: letras, números, símbolos y espacios. Cada código
se compone automáticamente de la forma más eficiente según lo que contenga.

  • Solo números ocupan menos espacio y caben más: hasta ~106 dígitos.
  • Con letras y símbolos caben menos: hasta ~54 caracteres.

El tamaño exacto depende del contenido, y el programa avisa si te pasas del máximo.

Para que se lea bien, el código necesita un poco de "aire" (zona en blanco) a los
lados.

Formato y capacidades

  • Ancho y Alto se fijan a mano. El ancho nunca puede quedar por debajo de un
    mínimo para que el código se pueda leer.
  • El texto legible puede ir debajo o encima del código (no a los lados).

Valor de muestra y columna Excel

Por defecto muestra un valor de ejemplo. También puedes usar una columna de
Excel: al seleccionarla se validan todas las filas y, si alguna está vacía o
es demasiado larga, aparece en el visor del diálogo indicando qué fila falla.

El origen de los datos

Como en todas las simbologías, el valor del código puede salir de tres sitios:

Origen Qué hace
Texto fijo Escribes el valor a mano en el perfil
Columna de datos externos El valor viene de una columna de Excel/CSV, fila a fila
Numeración interna El valor se genera con una máscara (p. ej. 0000 → 0001)

Para las 3 se aplican las mismas reglas del código (tamaño, posición del texto, etc.).

Campos del diálogo

Campo Qué hace
Ancho Tamaño horizontal del código
Alto Altura del código
Fuente Tipo de letra del texto legible
Cuerpo Tamaño de letra del texto. 0 = sin texto
Posición Lugar del texto: debajo o encima del código
Distancia Espacio entre el código y el texto

Para ocultar el texto legible, pon Cuerpo en 0: el código se queda solo,
sin texto alrededor.

A diferencia del QR o el PDF417, en el Code 128 el texto no admite las 9
posiciones de alineación ni colocarse a los lados: solo va debajo o encima.

El tipo de letra del texto (Fuente)

El texto legible que acompaña al código se dibuja con la letra que elijas en el
campo Fuente.

Las letras OCR (OCR-A, OCR-B y sus variantes) son las clásicas de los códigos de
barras: cada cifra está diseñada para que el lector la distinga sin errores. No
incluyen caracteres especiales (la ñ, acentos como á/é, ni símbolos); es una
tipografía propia del código de barras. Si tu texto necesita esos caracteres, elige
Helvetica (en Mac) o Arial (en Windows), que son las fuentes normales y sí
los tienen.

Errores típicos

Error Causa Solución
Texto demasiado largo Más de ~54 caracteres con letras, o ~106 solo números Acorta el texto o reparte en varios códigos
Dato vacío en columna Alguna fila no tiene valor Rellena la fila o quita esa fila de la columna
