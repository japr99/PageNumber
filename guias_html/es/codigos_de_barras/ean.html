Guía de Códigos de Barras — EAN-13 / EAN-8 / EAN-5

Qué es y para qué sirve

El EAN es la familia de códigos de barras más conocida, la que se ve en casi
todo producto de supermercado y tienda. Es un código numérico de barras verticales.
Según la variante:

Variante Dígitos Para qué se usa
EAN-13 13 Código estándar de producto
EAN-8 8 Productos pequeños con poco espacio
EAN-5 5 Complemento de precio (suele ir junto a un EAN-13)

Qué guarda el código

Solo números (sin letras ni símbolos). El último dígito es el dígito de
control: se calcula solo para que el lector sepa si el código se ha leído bien.

  • EAN-13: 13 dígitos. El primer dígito no puede ser 0. Si escribes 12 dígitos,
    el programa calcula el dígito de control; si escribes 13, lo comprueba.
  • Los primeros dígitos identifican el país (sistema de numeración): por
    ejemplo, los códigos que empiezan por 84 son de España. Es un dato que va
    dentro del propio código y el programa lo respeta tal cual.
  • EAN-8: 8 dígitos. Si escribes 7, el programa calcula el dígito de control; si
    escribes 8, lo comprueba.
  • EAN-5: exactamente 5 dígitos. No tiene dígito de control propio; se usa como
    complemento (por ejemplo para indicar el precio).

En el diálogo puedes escribir 13 (o 8) dígitos completos, o dejar que el programa
calcule el dígito de control.

Valor de muestra y columna Excel

Por defecto muestra un valor de ejemplo. También puedes usar una columna de
Excel: al seleccionarla se validan todas las filas y, si alguna está vacía,
no tiene los dígitos correctos o el dígito de control falla, aparece en el
visor del diálogo indicando qué fila tiene el problema.

El origen de los datos

Como en todas las simbologías, el valor del código puede salir de tres sitios:

Origen Qué hace
Texto fijo Escribes el valor a mano en el perfil
Columna de datos externos El valor viene de una columna de Excel/CSV, fila a fila
Numeración interna El valor se genera con una máscara (p. ej. 0000 → 0001)

Para las 3 se aplican las mismas reglas del código (tamaño, etc.).

Los dígitos del código

En el EAN los números van dentro del código, entre las barras, como parte del
propio símbolo (no es un bloque de texto aparte que puedas mover). Ajustas su tamaño
con la casilla Cuerpo.

Campos del diálogo

Campo Qué hace
Ancho Tamaño horizontal del código
Alto Altura del código
Fuente Tipo de letra de los dígitos del código
Cuerpo Tamaño de letra de los dígitos. 0 = sin texto

Para el EAN-5 hay también un campo Distancia para separar el código del
complemento.

A diferencia del QR, el PDF417 o el Code 128, en el EAN no se puede mover el
texto alrededor del código: los dígitos van fijos dentro de las barras.

El tipo de letra de los dígitos (Fuente)

Los dígitos del código se dibujan con la letra que elijas en el campo Fuente.

Las letras OCR (OCR-A, OCR-B y sus variantes) son las clásicas de los códigos de
barras: cada cifra está diseñada para que el lector la distinga sin errores. No
incluyen caracteres especiales (la ñ, acentos como á/é, ni símbolos); es una
tipografía propia del código de barras. Como el EAN es solo números, la OCR es la
recomendada. Si tu texto necesitara caracteres especiales, usarías Helvetica (en Mac)
o Arial (en Windows), que son las fuentes normales y sí los tienen — aunque en el EAN
solo entran dígitos.

Errores típicos

Error Causa Solución
Debe tener 12 o 13 dígitos El EAN-13 tiene otra longitud Comprueba la cifra (13 dígitos)
Debe tener 7 u 8 dígitos El EAN-8 tiene otra longitud Comprueba la cifra (8 dígitos)
El primer dígito no puede ser 0 EAN-13 empezando por 0 Ese rango es para otro código; cambia el primer dígito
El dígito de control no coincide Última cifra mal calculada Recalcula el dígito de control o deja que el programa lo haga
Debe tener exactamente 5 dígitos El EAN-5 tiene otra longitud Comprueba la cifra (5 dígitos)
Dato vacío en columna Alguna fila no tiene valor Rellena la fila o quita esa fila de la columna
