Guía de Códigos de Barras — PDF417

Qué es y para qué sirve

El PDF417 es un código bidimensional (aspecto de rectángulo con textura) pensado
para guardar bastante texto en poco espacio. Es muy usado en logística y
paquetes, envíos y albaranes, carnés y documentos.

Qué guarda el código

Puede guardar cualquier texto: letras, números, símbolos, espacios, y varias
líneas si las separas con |.

No hay restricción de caracteres: todo lo que escribas se codifica tal cual. Solo se
comprueba que el dato no esté vacío.

Formato y capacidades

El programa decide automáticamente el tamaño según el texto.

  • No hay un límite fijo de caracteres: cuantos más datos lleva, más grande se
    vuelve el código. El tamaño mínimo se calcula según el dato más largo que vayas a
    imprimir.

Como en el resto de códigos: si escribes un Ancho menor que el mínimo necesario,
el programa lo ajusta automáticamente para que el código quepa.

Valor de muestra y columna Excel

Por defecto muestra un valor de ejemplo. También puedes usar una columna de Excel
(por ejemplo la columna pdf417 de los archivos de ejemplo). Al seleccionar la
columna se validan todas las filas: si alguna está vacía, aparece en el visor
del diálogo indicando qué fila falla.

Varias líneas (texto legible bajo el código)

Igual que en el DataMatrix, puedes partir el texto en varias líneas para que la
app lectora distinga cada campo. Dos formas:

  • Separador |: lo más sencillo. Cada | separa un campo y cada campo es una
    línea.
  • Apertura / Cierre: defines qué carácter marca el inicio y cuál el fin de
    cada campo. El programa parte el dato usando esos caracteres (p. ej. apertura <<
    y cierre >>).

El texto legible no tiene por qué quedar siempre bajo el código: puedes posicionar
el bloque debajo, encima, a la izquierda o a la derecha, y alinearlo en las
9 posiciones (superior / medio / inferior × izquierda / centro / derecha).

El origen de los datos

Como en todas las simbologías, el valor del código puede salir de tres sitios:

Origen Qué hace
Texto fijo Escribes el valor a mano en el perfil
Columna de datos externos El valor viene de una columna de Excel/CSV, fila a fila
Numeración interna El valor se genera con una máscara (p. ej. 0000 → 0001)

Para las 3 se aplican las mismas reglas del código (tamaño, separadores, etc.).

Campos del diálogo

Campo Qué hace
Ancho (mm) Tamaño horizontal del código
Alto (mm) Altura del código
Fuente Tipo de letra del texto legible
Cuerpo Tamaño de letra del texto. 0 = sin texto
Alineación 9 posiciones del bloque de texto (superior/medio/inferior × izq/centro/der)
Interlineado Espacio entre líneas del texto (múltiplo)
Posición Lugar del bloque de texto: debajo, encima, izquierda o derecha
Distancia Espacio entre el código y el texto

Para ocultar el texto legible, pon Cuerpo en 0: el código se queda solo,
sin texto alrededor.

El tipo de letra del texto (Fuente)

El texto legible que acompaña al código se dibuja con la letra que elijas en el
campo Fuente.

Las letras OCR (OCR-A, OCR-B y sus variantes) son las clásicas de los códigos de
barras: cada cifra está diseñada para que el lector la distinga sin errores. No
incluyen caracteres especiales (la ñ, acentos como á/é, ni símbolos); es una
tipografía propia del código de barras. Si tu texto necesita esos caracteres, elige
Helvetica (en Mac) o Arial (en Windows), que son las fuentes normales y sí
los tienen.

Errores típicos

El PDF417 acepta casi cualquier valor, así que hay pocos errores:

Error Causa Solución
Dato vacío en columna Alguna fila no tiene valor Rellena la fila o quita esa fila de la columna
