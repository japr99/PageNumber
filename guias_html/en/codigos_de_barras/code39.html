Barcode Guide — Code 39

What is it and what is it used for

Code 39 is a one-dimensional barcode (only vertical bars in a single
line) that has been widely used for decades in inventory labels, logistics,
file identification, and asset management. It is simple, reliable, and compatible
with almost any reader.

Its name comes from the fact that each character is represented with a pattern of 9 elements
(3 wide and 6 narrow), hence the "39".

What the code stores

It can store uppercase letters, numbers, and some symbols (- . / + % space).

Additionally, if you type lowercase letters or other symbols (for example special
characters), the program automatically converts them to their compatible version using
a special encoding (Code 39 Extended): visually nothing changes in what you type;
it is just adjusted internally so the reader can understand it.

Rules to keep in mind:

  • The maximum is 41 data characters.
  • Asterisks * are used as start/end delimiters of the code; you should not type them as
    data.

Format and capabilities

  • Width and Height are set manually. The width can never be below a
    minimum for the code to be readable.
  • The human-readable text can go below or above the code (not on the sides).

Sample value and Excel column

By default it shows an example value. You can also use an Excel
column: when you select one, all rows are validated and, if any row is empty or
too long, it appears in the dialog viewer indicating which row fails.

Data source

As with all symbologies, the code value can come from three sources:

Source What it does
Fixed text You type the value manually in the profile
External data column The value comes from an Excel/CSV column, row by row
Internal numbering The value is generated using a mask (e.g. 0000 → 0001)

The same code rules (size, text position, etc.) apply to all three.

Dialog fields

Field What it does
Width Horizontal size of the code
Height Height of the code
Font Typeface of the human-readable text
Body Text font size. 0 = no text
Position Text location: below or above the code
Distance Space between the code and the text

To hide the human-readable text, set Body to 0: the code remains alone,
with no text around it.

Unlike QR or PDF417, in Code 39 the text does not support the 9
alignment positions or placement on the sides: it can only go below or above.

Text typeface (Font)

The human-readable text that accompanies the code is drawn with the typeface you
select in the Font field.

OCR fonts (OCR-A, OCR-B, and their variants) are the classic barcode fonts:
each digit is designed so the reader can distinguish it without error. They do
not include special characters (the ñ, accents like á/é, or symbols); they are a
typeface specific to barcodes. If your text needs those characters, choose
Helvetica (on Mac) or Arial (on Windows), which are standard fonts that do
include them.

Common errors

Error Cause Solution
Text too long More than 41 characters Shorten the text or split across multiple codes
Unsupported character A symbol that cannot be converted Use compatible characters (uppercase, numbers, - . / + %)
Empty data in column A row has no value Fill in the row or remove that row from the column
