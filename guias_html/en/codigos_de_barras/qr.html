Barcode Guide — QR

What is it and what is it used for

The QR (Quick Response) code is a two-dimensional square code
with a pattern in the corners that allows it to be read very quickly with any phone.

It is the best-known barcode because you scan it with your phone's camera. It is used for
web links, product information, tickets, business cards, restaurant menus,
and any short text you want to share.

It has built-in error correction so that even if part of the code gets dirty or
damaged, it still reads correctly.

What the code stores

It can store any text: letters, numbers, symbols, spaces, and multiple
lines if you separate them with |.

It only checks that the data is not empty. That said, to keep it readable,
it is recommended not to exceed about 200 characters: the more text, the denser and
harder to scan the code becomes. The program warns you if the data is too long.

Format and capabilities

  • The size is measured with a single value: the Size (mm), which is the side of
    the square (width = height).
  • The more data it carries, the larger the code needs to be. The minimum size is
    calculated based on the longest piece of data you are going to print.

As with the other codes: if you enter a Size smaller than the minimum
required, the program automatically adjusts it so the code fits.

Sample value and Excel column

By default it shows an example value. You can also use an Excel
column: when you select one, all rows are validated and, if any row is empty,
it appears in the dialog viewer indicating which row fails.

Multiple lines (human-readable text under the code)

Just like with DataMatrix, you can split the text into multiple lines so the
reader app can distinguish each field. Two ways:

  • | separator: the simplest. Each | separates a field and each field becomes a
    line.
  • Opening / Closing: you define which character marks the start and which the end of
    each field. The program splits the data using those characters (e.g. opening <<
    and closing >>).

The human-readable text does not have to always appear under the code: you can position
the block below, above, to the left, or to the right, and align it in the
9 positions (top / middle / bottom × left / center / right).

Data source

As with all symbologies, the code value can come from three sources:

Source What it does
Fixed text You type the value manually in the profile
External data column The value comes from an Excel/CSV column, row by row
Internal numbering The value is generated using a mask (e.g. 0000 → 0001)

The same code rules (size, separators, etc.) apply to all three.

Dialog fields

Field What it does
Size (mm) Side of the square (width = height)
Font Typeface of the human-readable text
Body Text font size. 0 = no text
Alignment 9 positions for the text block (top/middle/bottom × left/center/right)
Line spacing Space between text lines (multiple)
Position Location of the text block: below, above, left, or right
Distance Space between the code and the text

To hide the human-readable text, set Body to 0: the code remains alone,
with no text around it.

Text typeface (Font)

The human-readable text that accompanies the code is drawn with the typeface you
select in the Font field.

OCR fonts (OCR-A, OCR-B, and their variants) are the classic barcode fonts:
each digit is designed so the reader can distinguish it without error. They do
not include special characters (the ñ, accents like á/é, or symbols); they are a
typeface specific to barcodes. If your text needs those characters, choose
Helvetica (on Mac) or Arial (on Windows), which are standard fonts that do
include them.

Common errors

Error Cause Solution
Empty data in column A row has no value Fill in the row or remove that row from the column
Text too long More than ~200 characters Shorten the text or use PDF417 if you need much more
