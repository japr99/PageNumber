Barcode Guide — UPC-A / UPC-E

What is it and what is it used for

The UPC is the most widely used product barcode in the United States and
Canada (the "American cousin" of the EAN). That is why you will see it on North American
products or on labels designed for that market. It is a numeric vertical-bar code.

Variant Digits Used for
UPC-A 12 Standard product code in US/Canada
UPC-E 6 Compact version for small products

The UPC-E is a compact form of UPC-A: it stores the same information with fewer
digits when the code allows it, ideal for labels with limited space.

What the code stores

Numbers only (no letters or symbols).

  • UPC-A: exactly 12 digits. The last digit is the check digit, which is
    verified so the reader can tell if the code was read correctly.
  • UPC-E: exactly 6 digits. The first digit must be 0 or 1 (it identifies the
    number family of the system). The rest are the data.

As it is a product code, it works the same as the EAN: the numbers are inside the
code, between the bars.

Sample value and Excel column

By default it shows an example value. You can also use an Excel
column: when you select one, all rows are validated and, if any row is empty,
does not have the correct digits, or the check digit fails, it appears in the
dialog viewer indicating which row has the problem.

Data source

As with all symbologies, the code value can come from three sources:

Source What it does
Fixed text You type the value manually in the profile
External data column The value comes from an Excel/CSV column, row by row
Internal numbering The value is generated using a mask (e.g. 0000 → 0001)

The same code rules (size, etc.) apply to all three.

Code digits

In the UPC, the numbers are inside the code, between the bars, as part of the
symbol itself (not a separate text block you can move). You adjust their size
with the Body field.

Dialog fields

Field What it does
Width Horizontal size of the code
Height Height of the code
Font Typeface of the code digits
Body Font size of the digits. 0 = no text

Unlike QR, PDF417, or Code 128, in the UPC the text cannot be moved
around the code: the digits are fixed inside the bars.

Digit typeface (Font)

The code digits are drawn with the typeface you select in the Font field.

OCR fonts (OCR-A, OCR-B, and their variants) are the classic barcode fonts:
each digit is designed so the reader can distinguish it without error. They do
not include special characters (the ñ, accents like á/é, or symbols); they are a
typeface specific to barcodes. Since the UPC is numbers only, OCR is the
recommended choice. If your text needed special characters, you would use Helvetica (on Mac)
or Arial (on Windows), which are standard fonts that do include them — although in the UPC
only digits are used.

Common errors

Error Cause Solution
Must have 12 digits The UPC-A has a different length Check the count (12 digits)
Must have 6 digits The UPC-E has a different length Check the count (6 digits)
The first digit must be 0 or 1 The UPC-E starts with a different digit Change the first digit to 0 or 1
Check digit does not match Last digit calculated incorrectly Recalculate the check digit
Empty data in column A row has no value Fill in the row or remove that row from the column
