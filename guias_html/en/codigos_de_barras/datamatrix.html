Barcode Guide — DataMatrix

1. DataMatrix (symbology family)

DataMatrix is a two-dimensional code that can work in three different
ways, depending on the option you choose in the selector:

Selector option What the code stores
Custom DataMatrix Any free text (your own data, multiple lines, a URL…)
GS1 DataMatrix GS1 data in (AI)value format: (01)...(17)...
DataMatrix GS1 Digital Link The same GS1 data, but within a web address (URL)

All three share the physical configuration of the code (size, format, and
human-readable text under the symbol), which is explained at the end of this section. What
changes between them is what you write in the data. Each one is detailed
below.

1.1 Custom DataMatrix

This is the "standard" DataMatrix: it stores whatever you want, without validating any
standard. It only checks that it is not empty.

  • Single line: type the text directly.
  • Multiple lines: use the separator character (\| by default) between each
    text; each separated block becomes a different line.

Examples:

Customer: 1001 | Name: Maria Garcia Lopez | ID: 12345678Z
ABC12345
https://example.com/product

The first one generates 3 readable lines (one for each |). The others generate a single
line. This is useful for entering your own software data without following GS1.

Adapting the code to the reader (field start and end)

To let the reader app distinguish each field, you define two controls:

  • Opening: the character that marks the start of each field.
  • Closing: the character that marks the end of each field.

The program splits the data into fields using these characters (removes the initial
opening, splits on closing+opening, removes the closing from the last one). Each field
appears as a readable line under the code so the reader app can identify
where one field ends and the next begins.

  • Internal value — the "Edit text" button opens a window: you type the
    data, define opening and closing, and see live how each field looks.
  • External data — when you choose the column, the program tries to detect the
    separator automatically (it tries several characters until it finds the one that
    splits the rows into the same number of fields). This is only a suggestion and is not
    entirely reliable     — if the character also appears within the data
    (e.g. commas in an address) or the rows do not always have the same number
    of fields, it may pick the wrong candidate or fall back to | by
    default—; always verify that Opening and Closing match the actual separator.

In the example data files, there are columns with different separators you can
try:

Column Separator Opening / Closing in the profile
datamatrix_pipe \| empty / \|
datamatrix_semicolon ; empty / ;
datamatrix_chevron << >> << / >>
datamatrix_brace { } { / }

Example with opening << and closing >>:

<<Customer: 1001>><<Name: Maria Garcia Lopez>><<ID: 12345678Z>>

→ three fields: "Customer: 1001", "Name: Maria Garcia Lopez", "ID: 12345678Z".

With Opening empty and Closing |, this is the classic behavior:
Customer: 1001 | Name: ... | ID: ....

With both separators empty, the data is a single field.

These text lines do not have to always appear under the code: you can
position them anywhere around it (below, above,
to the left, or to the right) and align them in the 9 possible positions
(top / middle / bottom × left / center / right) using the
HRI Position and HRI Alignment fields in the profile.

1.2 GS1 DataMatrix

A variant for product identification using the GS1 standard. Data is
organized by Application Identifiers (AI) — each AI is a number that
identifies what the following value means.

Input format

Each block is written as (AI)value with no spaces between blocks:

(01)09506000117843(17)250124(10)POIG8F(21)1CBFNO6B9M

The parentheses are only for human readability. When the code is generated they are removed and
an invisible separator character is injected between variable-length fields.

Common examples

Use Example
Product + batch + date (01)09506000117843(17)250124(10)LOTE001
Product + serial (01)09506000117843(21)SERIE12345
Product + batch + serial (01)09506000117843(10)LOTE001(21)SERIE12345

Excel column

Each cell must contain the complete format with parentheses:

(01)09506000117843(17)250124(10)POIG8F(21)1CBFNO6B9M

When you select the column, all rows are validated. If there are errors they appear
in the dialog viewer indicating which rows fail and why. GS1 data is not
split by separators: it uses its own structure, which is why the "GS1 data detected"
label is displayed.

Common errors

1.3 DataMatrix GS1 Digital Link

Source for this explanation: GS1 Digital Link standard from GS1 Spain
(https://www.gs1es.org/estandares-gs1-identificar/gs1-digital-link/).

What is it?

GS1 Digital Link is the GS1 standard that embeds the GS1 identification
system within a web address (URL). The barcode no longer
stores just "the product number" but rather a link that leads to that product's web page.

The great advantage is how it is read: today, most people carry a phone that
does not understand a classic GS1 code, but any phone can scan a URL with the camera
and open the web page automatically. Although GS1 Digital Link became popular with QR codes,
it can also go into a DataMatrix, which is exactly this option in the selector.

What does it bring to your client (and to you)?

  • Direct access to content: the consumer scans and sees ingredients,
    allergens, usage instructions, recipes, related products, or the brand's
    online store.
  • Fewer labels: concentrates all the information that today would
    require printing several labels or codes into a single code.
  • Traceability: with the batch, expiry date, or best-before date inside
    the code, expired products, those with food alerts, or counterfeit items can be
    removed from the warehouse.
  • Easier returns for the distributor and better data exchange
    with business partners.
  • Gradual implementation: you can start with just the GTIN (the simplest
    case) and add more "application identifiers" as needed.
  • Sustainability and digital product passport: enables linking carbon footprint,
    recycling, or refurbishment data (a requirement driven by the
    European Union).

How does it differ from the traditional GS1 DataMatrix?

Both use the same identifiers (AI) and are functionally
equivalent: they say the same thing about the product. The difference is only how the data is
written:

GS1 DataMatrix (element string) GS1 Digital Link (URL)
How it is written (01)09506000117843(17)250124 https://id.gs1.org/01/09506000117843/...
What reads it Industrial scanners Phone with camera (opens the web)
Purpose Inventory and logistics Connecting with the consumer and the web

Input format

A GS1 Digital Link is a URL that includes the GS1 domain and, then,
identifiers (AI) separated by forward slashes /. Variable-length
fields (like batch or serial number) are also written in the
link and, if needed, date fields go at the end as ? parameters:

https://id.gs1.org/01/{GTIN}/10/{lot}?17={expiry}&21={serial}

Real example:

https://id.gs1.org/01/09506000117843/10/POIG8F?17=250124&21=1CBFNO6B9M

Common examples

Use Example (GS1 Digital Link URL)
Product + batch + serial https://id.gs1.org/01/09506000117843/10/LOTE001?21=SERIE12345
Product + batch + date https://id.gs1.org/01/09506000117843/10/LOTE001?17=250124
Product + serial + date https://id.gs1.org/01/09506000117843/10/LOTE001?17=250124&21=SERIE12345

Important rule with dates

Fixed-length date identifiers (like 17 for expiry, 15 for
best-before…) can appear in the link before a variable-length
field, but once a variable-length field appears (like batch 10 or serial
21), dates move to the ? parameters at the end. This rule is
enforced by the standard itself and the program validates it automatically.

Excel column

You can use an Excel column with a full GS1 Digital Link URL per cell.
When you select the column, all rows are validated: each value must be
a valid GS1 Digital Link URL (any random web address will not work).

  • If you need to store a free URL without validation, use the
    Custom DataMatrix variant instead of this one.

Common errors

Error Cause Solution
Invalid GS1 Digital Link URI: ... The address does not meet the standard Check that it starts with https://id.gs1.org/01/...
Invalid GS1 Digital Link URI You entered a plain URL without GTIN 01 Use Custom DataMatrix or add 01/{GTIN}

Tip: if the data is a long link, remember that, as with the other two
variants, the code gets larger and more square (see "Code sizes"
below). With very long URLs only the square format will be available.

Dialog fields

These are the same as the rest of the DataMatrix family (see 1.4). In this
variant there are no field separators: the human-readable text under the code shows the
full URL.

1.4 Common to the family (code configuration)

Dialog fields

Field What it does
Width Horizontal size of the code in mm
Height The 3 available GS1 sizes — choose the one you prefer (if the data is long, there will only be 1: the square one)
Format Square (automatic) or rectangular
HRI Font Typeface of the human-readable text under or above the code
HRI Body Text font size. 0 = no text
HRI Distance Space between the code and the text

To hide the human-readable text, set Body to 0: the code remains alone,
with no text around it.

Text typeface (Font)

The human-readable text that accompanies the code is drawn with the typeface you
select in the Font field.

OCR fonts (OCR-A, OCR-B, and their variants) are the classic barcode fonts:
each digit is designed so the reader can distinguish it without error. They do
not include special characters (the ñ, accents like á/é, or symbols); they are a
typeface specific to barcodes. If your text needs those characters, choose
Helvetica (on Mac) or Arial (on Windows), which are standard fonts that do
include them.

Code sizes

  • The Height is not typed: it is a selector with the 3 standard GS1 sizes that
    are calculated based on the width for DataMatrix (if the data is long, there will only be 1:
    the square one)    .
  • Choose the one that best fits your label; the program calculates the rest.

How is the minimum size calculated?

A barcode cannot be smaller than what its own data
allows: the more data it contains, the more modules it needs and the larger the minimum
width.

The program calculates that minimum from the data you are going to print:

  • With a sample value: the minimum is calculated from that single value.
  • With an Excel column: all rows are scanned and the
    size each one would generate is calculated. The final minimum is from the row with
    the most data     (the one that generates the largest code).

This way, even if each row has a different amount of data, all codes in the
column are printed at the same size: the minimum needed for the largest code
to fit.

If you enter a width smaller than the minimum, the program automatically adjusts
it to the minimum value. The Height selector is recalculated to offer you the 3
possible GS1 sizes for that width.

Long data → square only

Due to GS1 standard limitations, rectangular formats (16×36, 16×48) only
accept up to 49 characters.

  • Data ≤ 49 characters → 3 height options (square + 2 rectangular).
  • Data > 49 characters → only the square remains: the height does not change (it
    equals the width) and the height selector shows only 1 option.

Summary: the longer the data, the larger and more square the code. This is not a
program error; it is a GS1 standard limitation.
