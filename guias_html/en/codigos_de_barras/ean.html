Barcode Guide — EAN-13 / EAN-8 / EAN-5

What is it and what is it used for

The EAN is the best-known family of barcodes — the one you see on
nearly every supermarket and store product. It is a numeric vertical-bar code.
Depending on the variant:

Variant Digits Used for
EAN-13 13 Standard product code
EAN-8 8 Small products with limited space
EAN-5 5 Price supplement (usually placed alongside an EAN-13)

What the code stores

Numbers only (no letters or symbols). The last digit is the check
digit: it is calculated automatically so the reader can tell if the code was read correctly.

  • EAN-13: 13 digits. The first digit cannot be 0. If you type 12 digits,
    the program calculates the check digit; if you type 13, it verifies it.
  • The first digits identify the country (numbering system): for
    example, codes starting with 84 are from Spain. This is data embedded in the code
    itself and the program preserves it as-is.
  • EAN-8: 8 digits. If you type 7, the program calculates the check digit; if
    you type 8, it verifies it.
  • EAN-5: exactly 5 digits. It has no check digit of its own; it is used as
    a supplement (for example to indicate the price).

In the dialog you can type the full 13 (or 8) digits, or let the program
calculate the check digit.

Sample value and Excel column

By default it shows an example value. You can also use an Excel
column: when you select one, all rows are validated and, if any row is empty,
does not have the correct digits, or the check digit fails, it appears in the
dialog viewer indicating which row has the problem.

Data source

As with all symbologies, the code value can come from three sources:

Source What it does
Fixed text You type the value manually in the profile
External data column The value comes from an Excel/CSV column, row by row
Internal numbering The value is generated using a mask (e.g. 0000 → 0001)

The same code rules (size, etc.) apply to all three.

Code digits

In the EAN, the numbers are inside the code, between the bars, as part of the
symbol itself (not a separate text block you can move). You adjust their size
with the Body field.

Dialog fields

Field What it does
Width Horizontal size of the code
Height Height of the code
Font Typeface of the code digits
Body Font size of the digits. 0 = no text

For EAN-5 there is also a Distance field to separate the code from the
supplement.

Unlike QR, PDF417, or Code 128, in the EAN the text cannot be moved
around the code: the digits are fixed inside the bars.

Digit typeface (Font)

The code digits are drawn with the typeface you select in the Font field.

OCR fonts (OCR-A, OCR-B, and their variants) are the classic barcode fonts:
each digit is designed so the reader can distinguish it without error. They do
not include special characters (the ñ, accents like á/é, or symbols); they are a
typeface specific to barcodes. Since the EAN is numbers only, OCR is the
recommended choice. If your text needed special characters, you would use Helvetica (on Mac)
or Arial (on Windows), which are standard fonts that do include them — although in the EAN
only digits are used.

Common errors

Error Cause Solution
Must have 12 or 13 digits The EAN-13 has a different length Check the count (13 digits)
Must have 7 or 8 digits The EAN-8 has a different length Check the count (8 digits)
The first digit cannot be 0 EAN-13 starting with 0 That range is for another code; change the first digit
Check digit does not match Last digit calculated incorrectly Recalculate the check digit or let the program do it
Must have exactly 5 digits The EAN-5 has a different length Check the count (5 digits)
Empty data in column A row has no value Fill in the row or remove that row from the column
