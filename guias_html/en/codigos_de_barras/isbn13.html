Barcode Guide — ISBN-13

What is it and what is it used for

The ISBN-13 is the barcode used for books. It is actually an EAN-13
reserved for book numbering (the ISBN code). It is designed for bookstores,
publishers, and warehouses to identify each title.

It can include, in addition to the code, an "ISBN" text header above the bars
so it is clear that it is a book.

What the code stores

Numbers only (no letters or symbols), and it must follow two rules:

  • Exactly 13 digits.
  • Must start with 978 or 979 (the prefix reserved for books).

The last digit is the check digit, which is verified so the reader can tell
if the code was read correctly.

Sample value and Excel column

By default it shows an example value. You can also use an Excel
column: when you select one, all rows are validated and, if any row is empty,
does not have 13 digits, does not start with 978/979, or the check digit fails,
it appears in the dialog viewer indicating which row has the problem.

Data source

As with all symbologies, the code value can come from three sources:

Source What it does
Fixed text You type the value manually in the profile
External data column The value comes from an Excel/CSV column, row by row
Internal numbering The value is generated using a mask (e.g. 0000 → 0001)

The same code rules (size, etc.) apply to all three.

The "ISBN" header and the digits

  • The digits are inside the code, between the bars (as with the EAN).
  • You can also enable the "ISBN" header that is drawn above the bars
    with the text ISBN + number. It is toggled with the Header field.

Dialog fields

Field What it does
Width Horizontal size of the code
Height Height of the code
Font Typeface of the code digits
Body Font size of the digits. 0 = no text
Header Shows or hides the "ISBN" text above the bars

Digit typeface (Font)

The code digits are drawn with the typeface you select in the Font field.

OCR fonts (OCR-A, OCR-B, and their variants) are the classic barcode fonts:
each digit is designed so the reader can distinguish it without error. They do
not include special characters (the ñ, accents like á/é, or symbols); they are a
typeface specific to barcodes. Since the ISBN is numbers only, OCR is the
recommended choice. If your text needed special characters, you would use Helvetica (on Mac)
or Arial (on Windows), which are standard fonts that do include them — although in the ISBN
only digits are used.

Common errors

Error Cause Solution
Must have 13 digits The ISBN has a different length Check the count (13 digits)
Must start with 978 or 979 The prefix is not for books Use a valid ISBN (978/979)
Check digit does not match Last digit calculated incorrectly Recalculate the check digit
Empty data in column A row has no value Fill in the row or remove that row from the column
