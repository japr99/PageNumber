Barcode Guide — ITF-14

What is it and what is it used for

The ITF-14 is a barcode designed for cases, pallets, and transport
packaging (not for the product on the shelf). It is the "large logistics code":
it is printed directly on cardboard and is used to identify the
shipping unit (a box containing multiple units). It is usually read by warehouse
scanners.

It is based on the Interleaved 2 of 5 symbology, but with a fixed size and format
designed for transport.

What the code stores

GTIN-14 (14 digits) normally, or GTIN-13 (13 digits) which the program
converts. Numbers only. The last digit is the check digit.

  • GTIN-14: exactly 14 digits. The first digit is the indicator (0 to 8)
    that usually distinguishes case levels (e.g. 1 = case, 2 = pallet…).
  • GTIN-13: exactly 13 digits. If you choose this, the program adds a 0 at the
    beginning     and recalculates the check digit to convert it to GTIN-14.

The dialog lets you choose between GTIN-14 and GTIN-13 depending on your data.

Printer type

ITF-14 prints its text according to the chosen print method (Flexo, Thermal, or
Laser). This automatically adjusts the minimum dimensions of the code (height and
border thickness, the "support bar" around it) so it can be read based on the
printing method.

  • Flexo (cardboard printing): requires the code to be larger and the border to be
    thicker.
  • Thermal / Laser: allow a smaller code and a thinner border.

You just need to choose how you are going to print; the program already proposes the correct
minimums for that method.

Human-readable text

Below the code, the number is displayed formatted in blocks in the logistics
style, e.g. 1 08 1234 567008 8 (grouped as the standard dictates). You can place it
below or above the code and adjust its size with the Body field.

This text is drawn with the code's font (OCR by default), without the need to
choose a typeface.

Sample value and Excel column

By default it shows an example value. You can also use an Excel
column: when you select one, all rows are validated and, if any row is empty,
does not have the correct digits, or the check digit fails (depending on whether it is GTIN-14
or GTIN-13), it appears in the dialog viewer indicating which row has the problem.

Data source

As with all symbologies, the code value can come from three sources:

Source What it does
Fixed text You type the value manually in the profile
External data column The value comes from an Excel/CSV column, row by row
Internal numbering The value is generated using a mask (e.g. 0000 → 0001)

The same code rules (size, printer type, etc.) apply to all three.

Dialog fields

Field What it does
Width Horizontal size of the code
Height Height of the code
Body Font size of the human-readable text. 0 = no text
Position Text location: below or above the code
Distance Space between the code and the text
Type GTIN-14 (14 digits) or GTIN-13 (13 digits)
Printer Flexo / Thermal / Laser (adjusts the minimums)

To hide the human-readable text, set Body to 0: the code remains alone,
with no text around it.

Common errors

Error Cause Solution
Must have 14 digits The GTIN-14 has a different length Check the count (14 digits)
Must have 13 digits The GTIN-13 has a different length Check the count (13 digits)
Check digit does not match Last digit calculated incorrectly Recalculate the check digit
Empty data in column A row has no value Fill in the row or remove that row from the column
