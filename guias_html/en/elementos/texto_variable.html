Guide — Variable text

What is it and what is it used for?

Variable text is a layout element that displays text on a piece. Unlike the numberer, it does not advance on its own with a sequence: its value can be fixed (sample text) or come from an Excel column (a different value for each piece).

It is used to print data that changes from piece to piece without numbering, such as names, dates, codes, references, or any other text from the data list.

Where does the value come from?

You can choose between two sources:

  • Sample text: you type the text you want displayed directly. Useful for testing or when the value is the same across all pieces.
  • Excel column: the text is taken from a column in the data file. Each row in the spreadsheet provides the value for one piece, so piece 1 shows the data from row 1, piece 2 from row 2, and so on.

Prefix and suffix

In addition to the text itself, you can add a prefix and a suffix that are printed before and after the value (e.g. prefix Ref., suffix (original)). These are added to the text and can have their own color.

Profiles

Each variable text uses a profile that stores how the text looks:

  • Font and style (regular, bold, italic…).
  • Size of the text.
  • Color of the text (the prefix and suffix can be colored separately).
  • Prefix and suffix.
  • Anchor / alignment: how the text is placed within its box and relative to the anchor point.
  • Letter spacing: extra space between characters.

When you create a variable text it uses the <Default> profile; you can create as many profiles as you need and choose which one each element applies.

Print colors

Each color (text, prefix, and suffix) can be defined in the color space you prefer based on the print destination:

  • RGB (red, green, blue): intended for screen (digital view, preview). If you are only going to print in CMYK, it is better to use CMYK.
  • CMYK (cyan, magenta, yellow, black): the standard for digital and offset CMYK printing. This is the usual mode for commercial jobs.
  • Spot ink (SPOT / Pantone): a specific premixed color printed on its own plate with its own ink. This is the correct mode for corporate or brand colors, because it reproduces the exact logo color without depending on the mixing of the four process colors.

For spot inks you can:

  • Choose a spot color from the available list.
  • Extract spot colors from the loaded PDFs in the project: the program detects them and makes them available so the text uses that exact brand color.
  • Adjust the ink percentage (0-100%) of each spot ink, so you can use lighter versions of the same color without creating a new one.

Important for printing: if the result is going to be printed in CMYK, define the colors in CMYK. Keep in mind that the color you see on screen is not the actual print color: the monitor shows an approximation managed by the system/monitor color profile and its calibration (which is why it depends on how your screen is set up and the lighting). Also, in CMYK the final color is not exact or universal: the same CMYK value depends on the color profile (ICC) that the print shop uses at output to translate it to real ink. That is why it may look different across screens, print shops, or profiles. If you need an exact and reproducible color, define it as a spot ink (Pantone), which is printed with its premixed ink on its own plate and is independent of the profile and the screen.

Placement

Like other elements, the variable text is dragged to the desired position on the page. You can rotate it, align it, and adjust its size. The content displayed in each piece updates based on the chosen source.

Difference from the numberer

Variable text displays fixed text or text from Excel, without automatic numbering. If what you need is a sequence of numbers that advances on its own (with start, end, increment, and mask), use the numberer; if you need a different data value per piece without numbering, use variable text.
