Guide — Numberers (Numbers)

What is it and what is it used for?

A numberer is an element of the layout that prints a number that automatically increases from one piece to the next (serial numbering). It is used to number tickets, stubs, receipts, entry passes, or any printed item that needs a sequence of numbers.

You place a numberer on the page and the program assigns each piece its corresponding number based on its position and the print run, without you having to type them in by hand.

How is the number calculated?

The sequence is global (applies to the entire print run and affects both sides):

  • Starting number: the number the series begins with.
  • Ending number: the number the series ends with.
  • Increment: how much each piece increases by (usually by 1).
  • Reverse: whether the series runs in reverse order (decreasing instead of increasing).
  • Copies: how the numbers are distributed among the copies of each piece.

The program calculates the number of each piece based on the page it is on, so the sequence is continuous and correct throughout the print.

The mask

The mask defines the format of the number using the 0 character. Each 0 reserves a position for a digit, and short numbers are zero-padded on the left.

Mask Example (number 5) Result
0000 5 0005
000 5 005
0 5 5

You can also combine the mask with letters or other characters (AB000 → AB005).

Profiles

Each numberer uses a text profile that stores how the number looks:

  • Font and style (regular, bold, italic…).
  • Size of the text.
  • Colors: the number, prefix, and suffix colors can each be set independently.
  • Prefix and suffix: text printed before and after the number (e.g. prefix Nº, suffix /24).
  • Thousands separator: enable it so large numbers are displayed with dots (or the local separator).
  • Letter spacing: extra space between characters.

When you create a numberer it uses the <Default> profile; you can create as many profiles as you need (each with its own font, color, and mask) and choose which one each numberer applies.

Print colors

Each color (number, prefix, and suffix) can be defined in the color space you prefer based on the print destination:

  • RGB (red, green, blue): intended for screen (digital view, preview). If you are only going to print in CMYK, it is better to use CMYK.
  • CMYK (cyan, magenta, yellow, black): the standard for digital and offset CMYK printing. This is the usual mode for commercial jobs.
  • Spot ink (SPOT / Pantone): a specific premixed color printed on its own plate with its own ink. This is the correct mode for corporate or brand colors, because it reproduces the exact logo color without depending on the mixing of the four process colors.

For spot inks you can:

  • Choose a spot color from the available list.
  • Extract spot colors from the loaded PDFs in the project: the program detects them and makes them available so the text uses that exact brand color.
  • Adjust the ink percentage (0-100%) of each spot ink, so you can use lighter versions of the same color without creating a new one.

Important for printing: if the result is going to be printed in CMYK, define the colors in CMYK. Keep in mind that the color you see on screen is not the actual print color: the monitor shows an approximation managed by the system/monitor color profile and its calibration (which is why it depends on how your screen is set up and the lighting). Also, in CMYK the final color is not exact or universal: the same CMYK value depends on the color profile (ICC) that the print shop uses at output to translate it to real ink. That is why it may look different across screens, print shops, or profiles. If you need an exact and reproducible color, define it as a spot ink (Pantone), which is printed with its premixed ink on its own plate and is independent of the profile and the screen.

Placement

Like other elements, the numberer is dragged to the desired position on the page. You can rotate it, align it, and adjust its size. The number is recalculated automatically based on the piece where it lands.

Difference from variable text

The numberer prints a number that advances on its own (start, end, increment, and mask). Variable text displays fixed text or text from an Excel column, without an automatic sequence. If you only need serial numbering, the numberer is your element; if you need a different value per piece without numbering, use variable text.
